# NecromancerFX

Paper 1.21.11 plugin and public Java API for custom mob definitions and cosmetic client events. Requires Java 21. The client mod is not included; protocol compatibility is provisional.

## Build
Run `gradle :api:build :plugin:build`, or use GitHub Actions. Artifacts are uploaded as `necromancerfx-jars`.

Commands: `/necromancerfx status`, `/necromancerfx mobs`, `/necromancerfx reload`.
